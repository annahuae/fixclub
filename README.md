# Fixclub

Закрытый инвайт-только каталог проверенных мастеров для UAE.

Stack: Next.js 15 (App Router) · Neon Postgres · Tailwind · custom cookie auth.

---

## Деплой с нуля (один раз)

### 1. Положи код на GitHub

Скачай этот zip, на github.com открой свой репозиторий, нажми **Add file → Upload files**, перетащи всё содержимое папки (НЕ саму папку — её содержимое). Commit.

### 2. Vercel

1. vercel.com → Add New → Project
2. Import репозиторий `fixclub`
3. Framework: Next.js (определится автоматически)
4. **Не нажимай Deploy сразу** — сначала переменные окружения:

| Variable | Value |
|---|---|
| `ADMIN_PASSWORD` | Длинный пароль, который знаешь только ты |
| `SESSION_SECRET` | Любая длинная случайная строка (>32 символов) |

`DATABASE_URL` появится автоматически на следующем шаге.

5. Нажми Deploy. Первый деплой упадёт без БД — это нормально.

### 3. База данных

1. В проекте на Vercel → вкладка **Storage** → Create Database → Neon Postgres
2. Region — поближе к UAE (например, eu-central-1 или ap-southeast-1)
3. Подключи к проекту fixclub
4. Vercel сам добавит переменные `DATABASE_URL` и т.д.
5. На вкладке Deployments нажми **Redeploy** на последнем деплое

### 4. Инициализация схемы

1. Открой сайт → `/admin` → введи `ADMIN_PASSWORD`
2. Перейди по адресу `https://твой-сайт.vercel.app/api/init`
3. Увидишь `{"ok": true}` — таблицы созданы

### 5. Создай первый инвайт-код

В `/admin?tab=invites` сгенерируй код. Отправь его первому участнику круга.

## Дальнейшие правки кода

Загружай новые файлы на GitHub (drag-and-drop в веб-морду), Vercel сам пересоберёт и задеплоит. Никаких команд в терминале.

## Структура

```
app/
  page.tsx            — лендинг (выбор: инвайт / запрос доступа)
  access/             — формы входа и запроса
  pending/            — экран ожидания после запроса
  masters/            — каталог, добавление, страница мастера
  admin/              — админка (запросы, инвайты, юзеры)
  api/init/           — однократная инициализация БД
lib/
  db.ts               — Postgres клиент + схема
  auth.ts             — сессии и админ-кука
  utils.ts            — словари, генератор кодов
components/
  nav.tsx, star-rating.tsx
```
